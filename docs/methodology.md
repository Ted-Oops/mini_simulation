# 原文复现协议与审计记录

本项目实现 Chiarella、Iori、Perelló 的原文模型。全部市场逻辑位于 `market/`，通过根目录 `main.py` 模拟与分析；不调用 API。原始论文在 `references/paper.pdf`。

## 明确恢复的设定

- 全部个体独立抽取非负指数权重：基本面、趋势、噪声；不存在按人数划分的纯类型配比。
- 三个基本情形为 (σ1,σ2,σn)=(0,0,1)、(10,0,1)、(10,1.2,1)。趋势扫描包含 2.0、2.8 等图中取值。
- 5000 人；参考期限 200；个体期限为向上取整的 200(1+g1)/(1+g2)，没有 200 的上限；风险厌恶按式 (6) 变化。
- 初始股数均匀分布于 [0,50]，现金独立均匀分布于 [0,15000]；初始基本价值和市场价格均为 300。
- 最小报价单位 0.0005，基本价值 GBM 波动参数 0.001，零算术漂移。
- 式 (1)—(11)、表 I 的连续数量需求；没有 50 股订单上限、没有累计预测收益 ±0.5 截断、没有外部补单。
- 可立即成交的订单逐档成交，价格不越过所选限价；余量转限价单；个体期限到时撤单。无成交时采用双边中间价代理，否则保持旧价。
- 检验总现金、总股票、非负账户、现金与库存预留约束；这些是有限账户实现的必要条件。
- 主样本 20 万事件。原文未声明剔除期，因此默认全样本，并另存剔除前 10% 后的统计，不能事后只报告有利阶段。

## 必须显式披露的原文缺项

| 问题 | 实现和敏感性口径 |
|---|---|
| τ_f 的数值 | 原文定义了基本面回归时间尺度，但未列出数值。固定 200 是待检验假设；另扫描 20、2000、20000、200000。独立实现材料另有 τ_f=τ_i 的解释，也单独检验。 |
| ε 的分布与 σ_ε | 原文称其为方差，模拟参数给 1e-4，但未完整给分布与调用方式。分别检查正态标准差 1e-4 和字面方差 1e-4；其他噪声尺度仅是非原参数诊断。 |
| 初始价格历史、零方差 | 检查平坦历史、噪声历史、基本价值波动尺度的历史。机器方差下界为 1e-16，并记录触发次数；冻结市场不能算作低波动复现。 |
| 空盘口启动与初始化 | 默认空盘口；另做固定基本价值的市场初始化，所有初始化事件也保存在事件文件内。初始化不在原文中明确声明，不能悄悄加入并称为完全一致。 |
| 个体再次入场的旧单 | 分别保留多笔活动订单或撤换旧单。多单模式需要现金和库存预留，避免同一资产重复承诺。 |
| 自成交 | 阻止自成交并记录次数，避免产生没有经济交易的成交量。 |
| 连续抽价与报价网格 | 分别检查连续抽价后四舍五入，以及直接在允许区间的有效报价格上均匀抽样。极窄区间可能没有有效报价格，必须报告冻结而非隐瞒。 |
| 初始资产和交易数量取整 | 原文公式使用连续数量，基准按连续处理；整数数量作为单独选项。 |
| 统计阈值与窗口 | 希尔估计同时保存完整样本 5% 与单侧正样本 5% 的口径；绝对收益自相关到 800；修正 R/S 在各非重叠窗口估计后平均，q=20。 |

原文接受稿和工作论文版本均已检索核对，以上缺项在目前读到的版本中仍未得到完整数值说明。后续文献中的独立实现只能作为实现分支证据，不能当作作者原始代码。

## 如何判定复现

1. 图 2：纯噪声不跟踪基本价值；加入基本面后明显跟踪并靠近基本价值；趋势项增加价格波动。必须同时检查绝对偏离、相对偏离、价格路径和成交活跃性。
2. 图 3—4：无趋势时收益尾较薄，加入趋势后尾变厚，希尔指数随趋势权重降低；区分左、右尾并报告跨种子不确定性。
3. 图 5：绝对收益自相关与修正 R/S 的持久性随趋势项出现。单个 β 值不构成严格长期记忆证明。
4. 图 6—10：买卖市价单不对称、限价距离和首档缺口的分布、平均盘口形状；所有距离单位明确记录。
5. 图 11：按来单规模分组的收益分布，以及缺口和收益尾指数的对应关系。复现原文图形关系不等同于现实市场因果识别。

每次试验保存源代码快照、配置、种子、逐事件 NPZ、资产检查、统计和失败信息。`status=success` 只表示程序完成且资产检查通过，**不表示论文结果复现成功**。不存在选择性删除不利种子或不利参数分支。

## 当前执行记录（持续更新）

- `results/sensitivity/pilot_std`、`results/sensitivity/pilot_variance`：噪声口径的 2 万步试验；两种口径均未完整复现。
- `results/sensitivity/original_std_fullpilot`：5 个情形、3 个种子、每组 20 万步；基本面比纯噪声更接近基本价值，但幅度和尾部未对齐原文。
- `results/sensitivity/replace_fullpilot`：撤换旧单分支；没有消除上述不匹配。
- `results/sensitivity/tau_f_sweep`：完整 τ_f 扫描；τ_f=20 有明确数值发散，失败记录保留。未找到可直接称为原文复现的固定尺度。
- `results/sensitivity/initialization_sweep`：噪声尺度、时钟、初始历史诊断；部分低噪声分支完全没有成交，不能把它们低偏离或低波动当作成功。
- `results/sensitivity/grid_round_fullpilot`、`results/sensitivity/individual_tau_fullpilot`：报价离散化及个体 τ_f 解释；仍有未对齐现象。
- `results/sensitivity/individual_low_noise_diagnostic`：显式标记为非原参数的诊断，不能代替论文复现。
- `results/sensitivity/market_warmup_*`、`results/sensitivity/long_initialization_diagnostic`：固定基本价值的初始化诊断，核查启动非平稳性。
- `results/sensitivity/unreported_tau_calibration`：τ_f=50、100、200、400、800 的补充尝试，50 的基本面情形数值发散；其余仍存在价值偏离，不能选择一个数值宣称复现成功。
- `results/baseline`：5 个核心情形 × 100 个种子 × 20 万事件。采用固定 τ_f=200、噪声标准差 1e-4、连续数量、有效报价格抽样、原始个体权重、事件时间。每项均保存全样本统计；另对所有种子统一核对剔除前 10%、后半段和最后 10% 的统计。

代码快照中保留的是各批次启动时的真实源文件。较早批次快照可能包含旧 `research/metrics.py`，这是当时使用的两个统计函数，不是调用旧市场；当前版本位于 `market/estimators.py`，数值定义不变。
